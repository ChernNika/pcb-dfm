# Тестовые платы

- `test/` — свои тестовые платы ядра (шаг 1.6), каждая на одну тонкость модели. Генерируются
  скриптом `make_boards.py` (писатель плат `dfm/board/kicad_writer.py`); зоны заливает сам KiCad.
- `demo/` — демо-платы из документов по классам, переведённые в `.kicad_pcb`. На них заранее
  известно, какие дефекты есть и где (`*.json` рядом: подписи ситуаций в мм, ось Y вверх).
  Это эталон для проверки правил в пункте 2. Сейчас: B1 (Л1–Л8), A7 (М1–М8), A3 (К1–К7);
  A5 (З1–З8). `a3_demo` — 4 слоя со стеком, у которого глубины слоёв как в документе (0; 0,2; 1,4; 1,6 мм),
  капля у V6 строится самим KiCad при перезаливке, микроотверстие M1, площадка J2 со смещением.
  `a5_demo` — вскрытия строит KiCad по правилам `.kicad_dru` (от готового отверстия), V6
  сдвигается ПОСЛЕ заливки (`a5_after_refill`) — устаревшая заливка; земля поля BGA — глухие
  переходные F.Cu → In1.Cu.
- `kicad_demos/` — демо-проекты из поставки KiCad 10 берутся прямо из `share/kicad/demos`.
- `open/` — открытые проекты с GitHub и других площадок; для каждого нужно указать источник и лицензию.

```powershell
python boards/make_boards.py                      # пересоздать test/ и demo/ (нужен KiCad для заливки зон)
python -m dfm compare boards/test/*.kicad_pcb -o out   # сверка: два пути + нарушения против DRC KiCad
```

Что выяснилось на этих платах о KiCad 10.0 (учтено в адаптере, проверено по Gerber):

- слой падстека от основной формы **ничего не наследует**: без формы — круг, без размера — площадки
  нет, без доли скругления — 0, без смещения — 0; в режиме front_inner_back незаданный B.Cu
  берёт форму Inner;
- у падстека custom окно маски — **круг** диаметром по ширине основной площадки в центре отверстия;
- DRC не проверяет зазоры и касания медной графики без цепи;
- зону-каплю, записанную вручную, `kicad-cli` при перезаливке **удаляет** и строит капли заново
  по настройке `(teardrops … (enabled yes))` каждого отверстия;
- стек без слоёв шелкографии и пасты KiCad принимает в плату, но в job-файл Gerber **толщины
  слоёв не пишет** — писатель плат выводит стек полностью;
- проверка «ширина пояска» DRC учитывает смещение площадки (`offset`) и стек площадки — как A3;
- вскрытие в заливке вокруг отверстия без площадки на слое KiCad строит от **готового** отверстия:
  Ø = d + 2·зазор (а ствол — сверло d + 2t_мет); правила `.kicad_dru` (`clearance`,
  `hole_clearance`, с условием на цепь, класс цепей и слой) заливка учитывает.

Выгрузки `kicad-cli` (Gerber, сверловка, отчёты DRC) складываются в папку отчёта `compare`
и в git не попадают.

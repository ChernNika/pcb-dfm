# PCB DFM

Анализатор технологичности печатных плат для KiCad 10. Проверяет ширину дорожек, зазоры, пояски отверстий и паяльную маску. Для участков с острыми углами оценивает риск избыточного травления. Результат — HTML-отчёт с отмеченными на плате проблемными местами.

## Установка плагина на Windows

1. Установите **KiCad 10** и **Python 3.11 или новее**. Для установки плагина и его первого запуска нужен интернет.
2. На странице проекта в GitHub нажмите зелёную кнопку **Code → Download ZIP**. В Проводнике щёлкните по скачанному архиву правой кнопкой мыши и выберите **Извлечь всё…**
3. Откройте распакованную папку, в которой рядом с `install.bat` лежат папки `dfm` и `plugin`. Дважды щёлкните `install.bat` и дождитесь сообщения **«Готово»**. Установщик возьмёт файлы плагина из этой папки.
4. Откройте в KiCad **Настройки → Параметры → Плагины**, включите **сервер IPC API** и перезапустите KiCad.

## Первая проверка

1. В редакторе печатных плат KiCad откройте свою плату или [пример b1_demo.kicad_pcb](boards/demo/b1_demo.kicad_pcb) из папки `boards/demo`.
2. На панели редактора нажмите **Проверить технологичность**. В браузере выберите профиль **«Открытые данные»** и нажмите **Проверить**.
3. После анализа откроется отчёт. Нажмите метку на схеме платы, чтобы перейти к описанию находки. Если у находки есть кнопка **Показать в KiCad**, она выделит соответствующий объект в редакторе.

## Запуск из PowerShell

После установки выполните из папки проекта:

```powershell
& "$env:USERPROFILE\.venvs\pcb-dfm\Scripts\python.exe" -m dfm check boards/demo/b1_demo.kicad_pcb --open
```

Вместо демоплаты можно указать свой файл `.kicad_pcb` или путь к папке с файлами Gerber и сверловки.
